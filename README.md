# 公歧导航（GongQi Nav）

一个**个人网址导航站**，支持多级分类、网址管理，并可与**飞书电子表格**做双向数据同步。

## 📌 项目简介

「公歧导航」是个人收藏的网址导航工具，具备：

- **大分类 + 多级子分类**：支持自行添加、删除、重命名各级分类；大分类可自由切换展示（默认每排 5 个）。
- **网址管理**：末级分类下可添加网址，自动拉取网页 Logo 或从 Logo 库选择；网址卡片支持编辑、删除、拖拽排序。
- **站内搜索**：支持按网址名称或 URL 搜索；顶部提供多引擎搜索（百度、搜狗、必应、翻译、微信、抖音等）。
- **数据本地持久化**：数据存储在浏览器 localStorage，编辑实时保存。
- **飞书表格双向同步**（核心功能）：网页编辑自动同步到飞书表格；在飞书表格中编辑也会同步回网页。

## ⚙️ 使用方式

### 方式一：纯本地使用（无需飞书同步）

直接双击打开 `我的导航站.html` 即可使用。所有数据保存在浏览器本地，增删改即时生效。

### 方式二：开启飞书双向同步（推荐）

1. **确保本机装有 Python 3**（推荐 3.8+）。
2. **填写同步服务凭证**：编辑 `sync_server.py`，填入你的飞书自建应用凭证（见「配置要求」）。
3. **启动同步服务**：
   - 方式 A：命令行运行 `python sync_server.py`（保持窗口开启）。
   - 方式 B：双击 `start_sync.vbs`（静默后台运行，无窗口）。
   - 方式 C：将 `start_sync.vbs` 放入 Windows「启动」文件夹，实现**开机自启**。
4. **打开导航站**：`我的导航站.html` 会自动连接本地同步服务（端口 8787）：
   - 启动时自动从飞书表格拉取最新数据；
   - 网页内每次编辑/增删/拖拽后自动推送回飞书表格；
   - 页脚会短暂显示「已同步到飞书」/「已从飞书拉取更新」提示。

> 同步依赖本机运行 `sync_server.py`。若未启动服务，网页仍可本地正常使用，只是不会同步到飞书。

## 🔧 配置要求

### 飞书开放平台自建应用

1. 登录 [飞书开放平台](https://open.feishu.cn/app) → 创建**企业自建应用**。
2. 记录应用的 **App ID** 与 **App Secret**（在「凭证与基础信息」页查看）。
3. 在「权限管理」中开通以下权限（均为**应用身份**）：
   - `sheets:spreadsheet`（查看、评论、编辑和管理电子表格）
   - `sheets:spreadsheet:create`（创建电子表格）
   - `sheets:spreadsheet:read`（查看电子表格）
   - `sheets:spreadsheet:readonly`（查看、评论和导出电子表格）
   - `drive:drive`（查看、评论、编辑和管理云空间中所有文件）※需企业管理员审核
4. 将应用**发布上线**（需企业管理员在「管理后台 → 工作台 → 应用审核」中通过）。

### sync_server.py 凭证配置

编辑 `sync_server.py` 顶部配置区：

```python
APP_ID     = "cli_xxxxxxxxxxxxxxx"   # 你的应用 App ID
APP_SECRET = "你的应用App Secret"     # 你的应用 App Secret
PORT = 8787                          # 端口（一般无需改）
```

### 可选：复用已有飞书表格

首次运行时，服务会自动用你的凭证**创建**一张新表格。若想使用已有表格，可在 `_sync/_config.json` 中填写：

```json
{
  "spreadsheet_token": "表格的spreadsheet_token",
  "sheet_id": "子表ID",
  "spreadsheet_url": "表格完整链接"
}
```

## 🔄 双向同步机制

```
网页(HTML)  ⇄  sync_server.py(本地服务)  ⇄  飞书电子表格
```

- **网页 → 飞书**：网页每次编辑后，通过 `POST http://127.0.0.1:8787/api/push` 推送最新数据。
- **飞书 → 网页**：网页启动/定时通过 `GET http://127.0.0.1:8787/api/pull` 拉取飞书最新数据。

同步服务 API：
| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/pull` | GET | 从飞书拉取导航数据 |
| `/api/push` | POST | 把导航数据写入飞书 |
| `/api/config` | GET | 查看当前配置（表格链接） |

## ❓ 常见问题

**Q1：网页编辑后飞书没更新？**
→ 确认本机 `sync_server.py` 正在运行（页脚出现「同步失败」提示即未运行）。

**Q2：飞书表格打不开 / 提示无权限？**
→ 表格权限为「组织内可编辑」，需与表格在同一企业（通城丝瓜传媒），且应用已发布上线。

**Q3：同步服务如何开机自启？**
→ 把 `start_sync.vbs` 放到 `Win+R` 输入 `shell:startup` 打开的目录中。

**Q4：`drive:drive` 权限审核需要多久？**
→ 该权限需企业管理员审核，在企业「管理后台 → 工作台 → 应用审核」中通过后即时生效。
