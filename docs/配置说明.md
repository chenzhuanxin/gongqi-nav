# 公歧导航 · 配置说明

本文档详细说明部署「公歧导航」所需的全部环境、配置与步骤。

---

## 一、环境要求

| 依赖 | 版本要求 | 说明 |
|------|---------|------|
| 操作系统 | Windows / macOS / Linux | 本项目为本地网页应用 |
| Python | 3.8+ | 运行同步服务 `sync_server.py` 所需 |
| 浏览器 | Chrome / Edge / Firefox 等 | 打开 `我的导航站.html` |
| 飞书账号 | 企业成员 | 用于飞书表格同步 |
| 飞书开放平台应用 | 已创建 | 提供同步凭证 |

> 同步服务仅用 Python 标准库，无需 `pip install` 任何第三方包。

---

## 二、飞书开放平台配置（完整步骤）

### 2.1 创建自建应用
1. 打开 [飞书开放平台](https://open.feishu.cn/app)。
2. 点击「创建应用」→ 选择「企业自建应用」。
3. 填写应用名称（如「公歧导航同步」）、描述、图标。
4. 创建成功后在「凭证与基础信息」页可看到 **App ID** 与 **App Secret**。

### 2.2 开通 API 权限
在「权限管理」中搜索并开通以下权限（应用身份）：

| 权限标识 | 权限名称 | 是否需要审核 |
|---------|---------|-------------|
| `sheets:spreadsheet` | 查看、评论、编辑和管理电子表格 | 否（免审） |
| `sheets:spreadsheet:create` | 创建电子表格 | 否（免审） |
| `sheets:spreadsheet:read` | 查看电子表格 | 否（免审） |
| `sheets:spreadsheet:readonly` | 查看、评论和导出电子表格 | 否（免审） |
| `drive:drive` | 查看、评论、编辑和管理云空间中所有文件 | **是（需审核）** |

### 2.3 发布上线
1. 在「版本管理与发布」创建版本，填写版本号（如 `1.0.0`）与更新说明。
2. 提交发布申请。
3. 由**企业管理员**在「飞书管理后台（admin.feishu.cn）→ 工作台 → 应用审核」中点击「通过」。

> 只有 `drive:drive` 需要审核；它用于把同步表格授权为「组织内可编辑」，实现飞书侧的编辑同步。

## 三、同步服务配置

### 3.1 填写凭证
编辑 `sync_server.py` 顶部：

```python
APP_ID     = "cli_aa374d4b47b8dbe3"   # ← 填你的 App ID
APP_SECRET = ""                        # ← 填你的 App Secret
PORT = 8787                            # 默认端口
```

### 3.2 启动服务

**命令行方式**（保持窗口开启）：
```bash
python sync_server.py
```

**后台静默方式**（无窗口）：
- 双击 `start_sync.vbs`。

**开机自启**：
1. 按 `Win + R`，输入 `shell:startup` 回车，打开启动文件夹。
2. 把 `start_sync.vbs` 复制进去。
3. 之后每次开机自动后台运行同步服务。

### 3.3 服务启动后输出
启动成功会打印：
```
公歧导航 <-> 飞书表格 双向同步服务
飞书表格: https://.../sheets/...
监听地址: http://127.0.0.1:8787
```

## 四、飞书表格权限设置（使企业成员可编辑）

同步服务首次运行会自动创建飞书表格。要让同企业成员可编辑，需将表格链接权限设为「组织内可编辑」：

1. 用应用凭证调用（或由应用管理）：
   `PATCH /open-apis/drive/v1/permissions/{token}/public?type=sheet`
   设置 `link_share_entity = "tenant_editable"`。
2. 或在表格右上角「分享」→ 链接分享中设为「企业内可编辑」。

> 本项目交付的表格已配置为「组织内可编辑」，同企业成员打开即可编辑。

## 六、常见问题排查

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| 页脚提示「同步失败」 | 同步服务未启动 | 运行 `python sync_server.py` |
| 飞书表格「只能阅读」 | 表格链接权限为只读 | 设为「组织内可编辑」 |
| 飞书表格打不开 | 非同一企业 / 应用未上线 | 确认企业与应用发布状态 |
| 网页编辑后飞书无变化 | 未触发同步 | 检查服务是否运行，刷新页面 |
| `drive:drive` 生效延迟 | 权限审核中 | 联系企业管理员在管理后台通过 |
